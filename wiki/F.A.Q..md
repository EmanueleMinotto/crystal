## There's a bug/I have a suggestion
Report it or fix/write it, read the [contributing guidelines](https://github.com/EmanueleMinotto/crystal/blob/master/.github/CONTRIBUTING.md) and open a pull request. (Thanks)

Following the original idea, nothing was defined in the test environment.
The framework is tested using GitHub Actions and [phpt files](http://qa.php.net/phpt_details.php) through PHPUnit.
